# 자동 차트 기법 분석

일반 종목 차트가 조회한 일봉 OHLCV를 사용해 브라우저에서 결정적으로 계산한다.
종목 분석 점수·진입가·손절가에는 영향을 주지 않으며 서버 분석 이력에 저장하지 않는다.
스크리너의 기본 차트는 기존 캔들·거래량 표시를 유지한다.

## 판정 규칙 v1.0

- 최소 60개 일봉 필요. 날짜 중복, 유효하지 않은 OHLCV는 판단 보류한다.
- 날짜순 정렬 후 최신 봉을 제외한 최대 120봉으로 기준을 구성한다. 최신 봉은 현재 위치와 누적 거래량 비교에만 사용한다.
- 좌우 3봉보다 엄격히 높은/낮은 극값을 확인된 피벗으로 사용한다. 동일 봉이 고점과 저점인 경우 순서를 알 수 없어 제외한다.
- 최근 14개 true range의 단순 평균을 변동폭 기준으로 사용한다. Wilder 방식 ATR과는 다르다.
- 0.5배 변동폭 이내의 피벗을 묶어 최소 2회 반복된 구간 중 현재가와 가까운 최대 4개를 표시한다.
- 박스권: 직전 20봉, 폭이 변동폭의 6배 이하, 양 경계에서 3봉 이상 떨어진 접촉이 각각 2회 이상, 종가 이동 효율 0.3 미만.
- 최신 가격이 박스를 벗어나면 돌파/이탈 '시도'로 표시한다. API에 봉 마감 여부가 없으므로 확정 신호로 표현하지 않는다. 거래량은 직전 20봉 평균과 최신 봉 누적량을 비교한다.
- 피보나치: 최근 교대 피벗 2개 사이 3봉 이상, 파동 크기 4배 변동폭 이상, 종가 이동 효율 0.55 이상, 되돌림 5% 이상 100% 미만. 박스권이면 보류한다.
- 종점 이후 고가·저가가 파동을 벗어났다면 해당 기준은 무효다. 이전 파동을 검색해 억지로 후보를 만들지 않는다.
- 이동평균 해석: 이전 봉까지의 20/60봉 평균과 20봉 평균의 5봉 전 대비 방향. 볼린저 폭은 20봉·2표준편차 기준이며, 최근 폭과 이전 19개 폭 평균의 0.75/1.25배를 비교한다.

이 수치들은 설명 가능한 초기 규칙이며 수익성이나 반등 확률로 검증된 값이 아니다.
입력에는 수정주가 여부·거래일 캘린더 정보가 없어 기업행위에 따른 단절과 누락 거래일은 별도로 판정하지 않는다.
다이버전스, 다른 주기, 수동 기준점, 서버 저장은 후속 범위다.

## 표시와 검증

보라색 띠는 지지·저항 후보, 주황선은 박스 경계, 청록선은 피보나치 비율과 기준 파동이다.
지지·저항, 피보나치, 박스권 버튼으로 각 표시와 범례를 독립적으로 전환하고, 판정 근거는 계속 읽을 수 있다.
피보나치를 끄면 비율별 가격선과 기준 파동 연결선을 함께 숨긴다.
종목·주기·가격 데이터 변경 시 재계산하며 기존 차트를 정리한다.

`npm test -- src/features/stock-chart`에서 파동 계산, 구간 무효화, 데이터 검증,
확인되지 않은 피벗 배제, 박스 돌파/거래량 비교 및 화면 전환을 검증한다.
